# repos

Layer 5. Arch-style repo view, generated by `tools/pkgbuild-graph.ts` (`just graph`): `core/` = runtime closure of msys `base`, `extra/` = other MSYS pkgbases, `mingw/` = native env pkgbases. Each `<pkgbase>/meta.json` points to the PKGBUILD in `third_party/` (no copies). Own pkgbases (aphrody-*) add a `PKGBUILD` next to meta.json. ISA variant repos (`*-v3/-v4/-znver4`) are binary-only (`formats/pacman`), not separate trees.
