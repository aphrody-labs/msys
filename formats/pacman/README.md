# formats/pacman

pacman format and repo db: .pkg.tar.zst + .sig, `<repo>.db`/`.files`, pacman.conf template with [aphrody-core] [aphrody-extra] [aphrody-mingw] and ISA variants [*-v3] [*-v4] [*-znver4] (CachyOS model, chosen by CPU detection at install). pacman: `third_party/msys2-pacman` (fork) + Arch upstream pinned from src.
