# formats/vcpkg

vcpkg bridge. `vcpkg.json` (manifest mode), `vcpkg-configuration.json` (overlay triplets: labs `infra/vcpkg/triplets` via pins + local `triplets/x64-mingw-llvm.cmake`). Registry: ports stay upstream (`$SRC_ROOT/third_party/vcpkg`, pin); our own ports would go to a git registry, not here. Binary caching: `VCPKG_BINARY_SOURCES=clear;x-aws,<R2 bucket>,readwrite` on fr2/CI (R2 is S3-compatible), never local. `MAPPING.md` / `mapping.json` are generated by `tools/vcpkg-map.ts`.
