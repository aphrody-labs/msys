# toolchains/llvm

LLVM-pure toolchain (clang, clang-cl, lld/lld-link, llvm-ar/rc/mt, compiler-rt, libc++/libunwind). Pin: `pins.toml` [labs].toolchain (Chromium clang). MinGW sysroot recipe: `third_party/llvm-mingw`. Used by CLANG64/CLANGARM64 and by the MSVC-ABI envs via clang-cl. Primary compiler of the distro (ADR 0003).
