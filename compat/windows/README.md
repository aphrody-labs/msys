# compat/windows

Windows-facing layer: env shells as Windows Terminal fragments, pwsh module (`formats/psgallery`), winget + DSC v3 configuration documents, registry-free activation, vcpkg overlay triplets for mingw/clang envs (`formats/vcpkg`), MSVC + SDK dev env bootstrap without the VS IDE. WSL/WSLg are design references only (ADR 0007): no WSL runtime.
